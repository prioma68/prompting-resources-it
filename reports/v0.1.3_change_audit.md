# v0.1.3 change audit

## Scope

This release corrects v0.1.2 against the integration plan captured in `conv3.txt`.

## Result

v0.1.2 had the correct structure but notes and chunks were too compressed. v0.1.3 keeps the architecture unchanged and expands the Brex integration as secondary/practitioner knowledge.

## Main corrections

- Expanded hidden prompt definition and security boundary.
- Expanded prompt hacking into jailbreak, prompt injection, prompt leakage and data exfiltration.
- Added defense-in-depth guidance: context filtering, untrusted content separation, output validation, tool validation, confirmations and logging.
- Expanded context assembly and Give a Bot a Fish.
- Expanded semantic search/RAG and HyDE as controlled advanced pattern.
- Expanded command grammars, command abstraction level, JSON command output and ReAct.
- Expanded data formats with list/table/JSON/XML/delimited/relational examples.
- Added citation IDs and source traceability as explicit concepts.
- Expanded programmatic output and validation guidance.
- Preserved fine-tuning as last resort and removed dated model-specific claims from operational notes.
