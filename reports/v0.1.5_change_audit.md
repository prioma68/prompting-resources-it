# Change audit v0.1.5

## Baseline

Baseline operativa disponibile nella sandbox: `ai-docs-repository-v0.1.3.zip`.

Nota: l'utente ha indicato v0.1.4 come release pubblicata con file di governo progetto, ma l'artefatto v0.1.4 non era presente nella sandbox. La v0.1.5 include comunque i file di governo progetto richiesti e documenta la continuita'.

## Editorial decision

Arthur Shield / Arthur AI e' stato integrato parzialmente come fonte secondaria strategica per runtime guardrails and LLM safety. Non e' stato promosso a fonte primaria di prompt engineering.

## Included

- rule placement: validate_prompt / validate_response
- hallucination detection: intrinsic vs extrinsic
- claim-by-claim evaluation
- prompt injection detection: jailbreaking / instruction manipulation
- sensitive data leakage su prompt e response
- PII leakage: direct identifier e quasi-identifier
- custom rules: regex e keyword
- default rules vs task rules

## Excluded by design

- benchmark numerici
- costi e latenze
- claim commerciali
- dettagli di setup
- esempi API completi
- tabelle lunghe non necessarie
