# Agentic workflows v0.1

## Pattern 1 - Research agent

Input: research question, source scope, success criteria.

Core ideas: retrieval budget from OpenAI, XML multi-document structure from Claude, ReAct from Google, operational research workflows from Perplexity.

## Pattern 2 - Coding agent

Input: task, repository path, constraints, tests.

Core ideas: validation loops from OpenAI, investigate-before-answering and safe tool use from Claude, code prompting from Google.

## Pattern 3 - Business workflow agent

Input: workflow objective, connected tools, approval rules.

Core ideas: Perplexity Comet/Tasks/Spaces, OpenAI stopping rules, Claude reversibility and safety, Google ReAct.

## Pattern 4 - Knowledge base assistant

Input: user question, corpus chunks, citation requirement.

Core ideas: transformed chunks, source references, XML or JSON packaging, retrieval budget and grounding evaluation.
