# Cos'è il prompting

Il prompting è il modo in cui formuliamo una richiesta a un modello linguistico per ottenere un risultato utile. Un prompt può contenere una domanda, istruzioni, contesto, esempi, vincoli, dati di riferimento e indicazioni sul formato dell'output.

## Definizione operativa

Un prompt efficace non è solo "una domanda". È un incarico formulato in modo abbastanza chiaro da orientare il modello verso il risultato atteso.

Componenti tipiche:

- obiettivo;
- contesto;
- ruolo o prospettiva;
- input o fonti;
- vincoli;
- formato dell'output;
- criteri di verifica.

## Prompting vs prompt engineering

Il prompting è l'atto di scrivere una richiesta.

Il prompt engineering è il processo iterativo di progettare, testare, misurare e migliorare prompt per ottenere risposte più accurate, utili, verificabili e coerenti.

## Idea guida

Un buon prompt deve rispondere a queste domande:

1. Che cosa voglio ottenere?
2. Su quali informazioni deve basarsi il modello?
3. Quali limiti deve rispettare?
4. In quale forma deve restituire il risultato?
5. Come capisco se la risposta è buona?
